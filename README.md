# 🦚 Krishna — The Divine Arrival

A cinematic, interactive **Krishna Janmashtami** landing page built with pure HTML, CSS and JavaScript.

## ✨ Features

- Cinematic midnight-blue + gold design
- Animated moon, stars, particles and diyas
- Responsive layout for mobile and desktop
- Scroll reveal animations
- Interactive symbols
- Janmashtami countdown
- 5-question Krishna quiz with score
- Result screen + replay
- No framework or build tool required
- GitHub Pages ready

## 📁 Files

```text
krishna-janmashtami/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Run locally

Just open `index.html` in a browser.

For a better development experience, use VS Code + Live Server.

## 🌐 Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload all four files.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide your live website URL.

## 🎯 Customize

### Countdown
Open `script.js` and update the `dates` object with the exact Janmashtami date for future years.

### Text
Edit the content directly inside `index.html`.

### Colors
Edit the CSS variables at the top of `style.css`.

## ⚠️ Note

The project uses emoji symbols instead of copyrighted artwork, so it works without requiring image assets. You can later replace the symbols with your own artwork or properly licensed images.
